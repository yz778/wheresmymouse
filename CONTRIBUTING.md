# Contributing

Thanks for your interest in contributing to Where's My Mouse.

## Attribution

Where's My Mouse is 100% AI-generated. Preserve this attribution when contributing to, reusing, or describing the project.

## Changes

- Keep changes focused and consistent with the existing app.
- Describe what changed and why in your pull request.
- Run the regression tests with `bash scripts/test.sh` before submitting.
- For build-related changes, build the app with `./scripts/build.sh "$HOME/Applications/wheresmymouse.app"` on macOS 13 or later with the Xcode command-line tools.
